# 🚗 Proyecto GTA

Módulo independiente dedicado al desarrollo, experimentación y prototipado del **Proyecto GTA** en Python.

---

## 📂 Estructura de este Módulo

```
gta/
├── notebooks/
│   └── gta_proyecto.ipynb      # Notebook interactivo para pruebas, simulación y código paso a paso
├── src/                        # Código fuente modular (clases, funciones, configuraciones)
│   ├── __init__.py
│   ├── config.py               # Constantes, tamaños de pantalla, parámetros de física
│   └── motor.py                # Clases principales: Jugador, Vehículo, Misiones
├── data/                       # Almacenamiento de datos, mapas, partidas guardadas o configuraciones
│   └── .gitkeep
├── docs/                       # Documentación técnica y hojas de ruta
│   ├── roadmap_gta.md          # Objetivos y opciones del proyecto
│   └── recursos_gta.md         # Enlaces a recursos, librerías y documentación
└── README.md                   # Este archivo
```

---

## 🚀 Cómo Empezar

Abre el notebook interactivo en [`notebooks/gta_proyecto.ipynb`](notebooks/gta_proyecto.ipynb) para ejecutar y probar las primeras clases y simulaciones.
